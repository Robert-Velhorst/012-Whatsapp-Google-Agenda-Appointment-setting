Operator help

The safe path from message to calendar event.

  1. Review detected intent.For Business API messages, check the conversation excerpt, proposed slots, timezone, and confidence.
  2. Send or share a proposal.Business API mode sends only when configured and approved. For personal WhatsApp, use Personal WhatsApp to paste a message, review the suggested times, then share the prepared draft yourself.
  3. Wait for contact confirmation.The contact can choose through the secure booking link. In personal mode, Agenda Relay cannot read chat replies or verify message delivery.
  4. Book the confirmed slot.An idempotent Google Calendar event is created after explicit slot selection, according to your approval settings.
  5. Handle follow-up manually for personal accounts.Personal WhatsApp confirmations and reminders are not sent by this app. Business API reminders outside the messaging window require an approved template.

Emergency behavior

Pause automation to stop Business API outbound messages, calendar changes, and reminder jobs. The assisted personal flow never sends messages on your behalf.
