Operator help

The safe path from message to calendar event.

  1. Review detected intent.Check the conversation excerpt, proposed slots, timezone, and confidence.
  2. Send a proposal.The official WhatsApp Cloud API sends the reviewed time choices and booking link.
  3. Wait for contact confirmation.The contact replies with 1, 2, or 3, or confirms through the secure booking link.
  4. Book the confirmed slot.An idempotent Google Calendar event is created and the result is recorded.
  5. Handle reminder exceptions.Reminders outside the messaging window require an approved WhatsApp template or remain manual.

Emergency behavior

Pause automation to stop outbound messages, calendar changes, and reminder jobs. Signed inbound messages continue to be recorded so work can resume safely.
